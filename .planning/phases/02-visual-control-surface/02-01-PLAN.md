<objective>
Extend the protocol, model, and bridge layers to support looper control commands (state changes, undo/redo, feedback) and cycle count tracking. This is the foundation layer that the UI components in Plan 02 will consume.

Purpose: The visual control surface needs to send commands to control loopers and track cycle counts. The protocol currently only supports discovery and status updates — we need command messages for control actions, and the model needs cycle count for the expanded detail view (per D-11, D-13).

Output: Extended ProtocolDefs constants, MessageProtocol command factories, BridgeClient convenience methods, cycle count in LooperState, Remote Script command handlers for Ableton Looper parameter manipulation, and passing C++ tests.
</objective>
