<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User click → OSC command → Remote Script → Live API | User input (clicks) triggers DAW parameter changes. Trust boundary at Remote Script command handler validates track_idx bounds |
| Plugin UI ← LooperTracker ← BridgeClient ← OSC ← Remote Script | State flows from DAW through IPC. Trust boundary at BridgeClient OSC input validates JSON structure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | TransportButton click → BridgeClient command | accept | Clicks are user-initiated, valid by definition. trackId comes from LooperTracker data (already validated from Remote Script) |
| T-02-05 | Denial of Service | Rapid state updates flooding UI repaint | mitigate | LooperTracker diff-based update (only notifies on actual state change per D-03) prevents unnecessary repaints. Timer-based refresh at 50ms throttles update rate |
| T-02-06 | Elevation of Privilege | Feedback slider out-of-range value | mitigate | juce::Slider constrains range to 0.0-1.0 at the UI level. BridgeClient sendSetFeedback sends the clamped value. Remote Script also validates on receipt |
